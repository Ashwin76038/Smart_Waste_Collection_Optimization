# Attribution and publication scope

OpenStreetMap road/POI/land-use context: © OpenStreetMap contributors, ODbL1.0; see https://www.openstreetmap.org/copyright and source S09. Raw regional extracts and large derivative geometry are not distributed in this source repository. Review ODbL requirements before redistributing a regenerated database.

Other context is attributed row-by-row in02_research/source_catalog.csv and acquisition_manifest.csv: Greater Chennai Corporation, Census of India, NASA POWER, OpenCity contributors, Coimbatore City Municipal Corporation, PPAC/parliamentary reference and US EPA. Community Coimbatore geometry is not certified as a current municipal boundary. Unknown reuse terms remain unknown; public accessibility does not establish redistribution permission.

All sensor, collection, hypothetical bin/fleet and modeled impact outputs are explicitly synthetic/assumed/derived. This repository does not grant a license to third-party datasets. No API credentials or raw private municipal operational data are included.
